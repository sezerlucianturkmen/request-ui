npm# Destek Talep Sistemi - React

Node.js 20.19+ ve npm kurulu olmalı. Backend çalışırken bu arayüzü başlatın:

```bash
npm install
npm run dev
```

Arayüz: http://localhost:5173

Giriş için backend'deki demo hesaplarını kullanın:

| Rol | E-posta | Parola |
|---|---|---|
| USER | `user@xmindsolutions.com` | `User123!` |
| USER | `user2@xmindsolutions.com` | `User234!` |
| ADMIN | `admin@xmindsolutions.com` | `Admin123!` |

Backend her açılışta talepleri ve demo kullanıcılarını sıfırlar.
